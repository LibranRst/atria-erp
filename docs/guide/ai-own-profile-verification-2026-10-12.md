# Own profile through AI chat

Ask “Ubah nama tampilan saya menjadi [nama]”, attach a photo and ask “Gunakan foto ini sebagai foto profil saya”, or ask “Hapus foto profil saya”. The assistant reads the actual own-profile context and prepares a compact before/after proposal. Select the intended image if more than one applies. Only **Simpan profil** applies it; **Koreksi lewat chat** requests a fresh proposal. Name-only edits preserve the photo. Removing a photo returns to initials without deleting the original files.

The photo source remains private. Human Save creates a cropped square profile copy using the configured ImageKit account. Own-profile inputs cannot alter credentials, email, roles, permission grants, finance or inventory. Current session rights and source versions are checked again at Save. Unchanged data needs no Save; stale/expired proposals require a new proposal. Confirmed history keeps its recorded result even if the profile changes again.
