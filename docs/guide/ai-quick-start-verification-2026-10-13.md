# Quick Start through AI chat

Ask “Bantu lanjutkan Quick Start”, “Tunda setup dulu”, “Lanjutkan setup yang ditunda”, or explicitly state whether there is legacy stock. The assistant reads the actual stored position and current Settings before preparing the next decision. Resume preserves the same step. Financial acknowledgement displays the configured cap/category ratios without modifying them. A retry records the current-stage attempt; it does not re-execute a project or monetary transaction.

At the first-project stage, provide the project name, an existing chosen client or a new client name, contract value and approved RAB value. Project Manager is optional, but a chosen manager must be active, belong to the company and have assigned-project scope. The assistant must ask for missing or ambiguous inputs. It must not infer client approval, invent a RAB amount or silently review a setup stage. Only the human **Buat proyek pertama** action commits the reviewed project, canonical category budget and completed Quick Start together. No client-facing RAB document is generated by that action.

Stock decisions change readiness metadata only. “No legacy stock” is blocked by actual nonzero physical/reserved inventory, including invalid negative balances or pending opening batches. Existing stock is entered through the separately approved opening-stock workflow. Completed Quick Start cannot be reset through chat. Ordinary subsequent project creation uses the existing project workflow.
