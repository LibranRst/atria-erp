# AI bank reconciliation verification

The new flow explicitly resolves a bank account, analyzes owned chat attachments or supplied mutations, reviews import rows, imports only selected rows, reads the stored queue, reviews exact cash candidates and confirms selected pairs. MARK_EXCEPTION records a human reason without making a transaction reconciled; CLEAR_EXCEPTION returns it to the unmatched queue. Matching clears an existing exception and writes paired status plus audit. None of these operations moves cash, creates a payment/expense or changes stock.

Core contracts reject missing account, invalid calendar date, non-cent money, client save payloads and 501 rows; exactly 500 are accepted. Exact reference can resolve a candidate set; arbitrary tie ordering cannot. Persisted draft review rejects altered stored statement facts, foreign candidates and reused cash records.

Disposable Postgres on loopback uses the guarded local preload to set ATRIA_TEST_DATABASE_URL.
