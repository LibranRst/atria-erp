# Dokumen Bisnis Atria

Dua halaman HTML mandiri. Buka langsung di browser — tidak butuh server, tidak
butuh build.

| Berkas | Isinya |
| --- | --- |
| `peluncuran-atria.html` | Semua tugas dan keputusan yang tersisa, dikelompokkan per pemicu waktu. Centangnya tersimpan di browser. |
| `bekal-bisnis-atria.html` | Kamus istilah, cara menetapkan harga, draf kesepakatan dengan bos, draf perjanjian vendor. |

Keduanya juga diterbitkan sebagai halaman yang bisa dibuka dari HP:

- Peluncuran — https://claude.ai/code/artifact/029c2dfa-4576-4ce2-8f8f-74be4b85b850
- Bekal Bisnis — https://claude.ai/code/artifact/9160d196-4028-4bd7-976f-0658c39b90d5

Sumbernya di sini yang jadi acuan. Setelah menyunting berkas di folder ini,
terbitkan ulang ke URL yang sama supaya versi HP ikut berubah.

## Kenapa HTML, bukan Markdown

Keduanya dibaca di luar editor — di HP, sambil ngobrol dengan bos, sebelum
menandatangani sesuatu. `peluncuran-atria.html` juga menyimpan centang, yang
tidak bisa dilakukan Markdown.

Keduanya berdiri sendiri dan **tidak tunduk pada `DESIGN.md`**. Sistem desain itu
mengatur antarmuka ERP-nya; dokumen ini bukan bagian dari aplikasi dan sengaja
punya identitas visualnya sendiri.
