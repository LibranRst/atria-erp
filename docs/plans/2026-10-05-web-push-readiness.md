## Follow-up: tray click marks the notification read

The physical Android test revealed that the tray tap opens the project but leaves the notification unread in Atria. The worker drops the payload's notification ID from notification data and its click handler only navigates; it never calls the existing read action.

Implementation plan:

1. Retain a validated notification UUID in the worker's notification data and include an internal read-intent marker in the safe destination on click. Recognize validated UUIDs in legacy `atria-<id>` tags so notifications displayed before the update can also be acknowledged.
2. Navigate immediately; do not wait for a network write in the service-worker click event. In the existing session-scoped notification provider, acknowledge the intent through the existing typed `markNotificationReadAction`. Backend session/tenant/recipient/project/permission scoping remains authoritative and the mutation remains idempotent.
3. Keep a bounded browser-local pending ID across offline and login/password gates; retry on authenticated session, connectivity and page focus. Drop the pending intent only after a successful ActionResponse. Remove only the internal URL marker through the shared URL helper, preserving other query/hash values.
4. Invalidate and refresh the existing notification store after acknowledgement so badge/list status updates and stale in-flight queries cannot restore unread state. Reading does not resolve an action-required notification or perform its business action.
5. Extend worker/controller/store tests for cold/existing app, modern/legacy IDs, unsafe/malformed data, failure/offline retry, session isolation and stale refreshes. Run workspace quality gates/build, then release only to the current public QA deployment and repeat the physical tray-tap test. No pilot deployment or database reset.

Reuse the existing NotificationsProvider/store, authenticated read action, shared URL-search helper, and notification UI primitives. No new visual primitive or public API endpoint is needed.
