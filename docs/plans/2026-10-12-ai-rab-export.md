Add a read-only export workflow: scoped project/revision lookup, immutable server-prepared export descriptor, human preview, format selection and actual PDF/XLSX/PNG downloads. No RAB approval, finance/stock mutation, AI receipt or external sharing is implied by export.

One-character search and multiple revisions require disambiguation; no silent first/project/current-revision fallback. Recheck thirty-day proof, selected source fingerprint and current grants before releasing each download. Changed, expired, revoked, missing or empty sources fail visibly without a misleading file.

Keep existing customization and explicit native sharing.
