# Brand yang dipakai saat ini

**Paduna** dipilih sebagai brand utama pada 17 Oktober 2026, menggantikan keputusan penggunaan sementara sebelumnya. Brand induk ini menaungi **Paduna Build** dan produk terpisah yang direncanakan, **Paduna Office**.

Keputusan dan aset yang berlaku untuk pekerjaan brand berikutnya ada di [panduan Paduna](paduna/README.md) dan [brand-system.json](paduna/brand-system.json).

Panduan Atria di folder `atria/`, paket PDF/ZIP Atria sebelumnya, dan paket Paduna provisional merupakan referensi historis. Simbol Temu, Manrope, dan palet ink-terracotta tetap digunakan. Paket lengkap Paduna v1 mencakup dokumentasi, brand book, naming map, aset, dan template; penerapan nama teknis pada aplikasi menjadi tahap berikutnya.
