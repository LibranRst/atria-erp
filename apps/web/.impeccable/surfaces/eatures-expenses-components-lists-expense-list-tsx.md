Inherit the current Atria Dashboard and Settings grammar: Manrope, cool canvas, compact semantic typography, white grouped owners, ink and terracotta, capsule controls and native HeroUI tables. This is a scoped extension of the established workspace, not a new brand or application shell.

The standalone canonical `/expenses` route adapts at >=1024px. Its header and peer tabs lead into a compact source-backed comparison band, status views, inline search/filters and one contextual collection. At >=1280px the native table and an independently sized 288px detail panel sit beside each other only when the active collection supplies actual row context; at 1024–1279px selecting a row moves from the list to its detail and a clear back action returns to the list. Empty and filtered-zero claims, bills and payments use the full table width without reserving an aside. Mobile, native `surface=mobile` fallback and project-embedded expenses retain their existing grouped composition. Keep the global shell untouched, use 16px section gaps and avoid oversized mobile summaries, decorative charts or repeated raised metric cards.
